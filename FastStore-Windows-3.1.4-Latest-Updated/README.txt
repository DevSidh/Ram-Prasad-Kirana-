FastStore for Windows — version 3.1.4

INSTALL
1. Close any open FastStore window.
2. Extract this ZIP to a folder on the billing computer.
3. Run RamPrasadBilling.exe.

Keep all files and folders from this ZIP together. Do not move the EXE by itself.
Your Windows bill records remain on the computer in the existing local storage
folders. Online order alerts, invoice search, pending payment search, and refund
search require the backend service to be deployed and reachable.

This is the Windows desktop package. It does not change or replace the Android
APK release.
