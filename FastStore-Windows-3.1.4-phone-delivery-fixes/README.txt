FastStore for Windows - phone, delivery profile, and billing fixes
Application version: 3.1.4+23

INSTALL / UPDATE
1. Close FastStore if it is currently running.
2. Extract this entire ZIP to a folder on the billing computer.
3. Run RamPrasadBilling.exe from that extracted folder.

Keep the EXE, DLL files, and data folder together. Do not run the EXE from
inside the ZIP or move it by itself.

This build limits phone entry to 10 digits and validates Nepal mobile numbers
starting with 97 or 98. Delivery staff can upload a profile photo from the
delivery app profile; saved photos appear in the admin staff list and customer
order tracking. In New Bill, the current bill remains visible while product
search results appear in a separate scrollable section.

Local bills and pending-cash files remain under
C:\Ramprasad store\bills.

Windows 10 or later, 64-bit, is required. If a Visual C++ runtime error
appears, install the Microsoft Visual C++ 2015-2022 Redistributable (x64)
from Microsoft's official site.
