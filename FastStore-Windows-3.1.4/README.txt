FastStore for Windows - version 3.1.4

INSTALLATION
1. Extract the complete ZIP to a folder on the billing computer.
2. Keep all extracted files together in that folder.
3. Run RamPrasadBilling.exe.

Do not run the EXE from inside the ZIP or move it by itself. The Flutter
runtime, plugins, and application data folder beside it are required.

REQUIREMENTS
- Windows 10 or later, 64-bit.
- Internet access for online features and account synchronization.
- If Windows reports a missing Visual C++ runtime, install the Microsoft
  Visual C++ 2015-2022 Redistributable (x64) from Microsoft's official site.

This is a Windows desktop build. Android APK installation and camera pairing
are Android-specific; connect a USB/Bluetooth barcode scanner to Windows or
use the app's supported phone pairing flow where configured.
